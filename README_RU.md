# CS2-AimAudit 🎯

**Аудит твоего аима — локальный разбор демок CS2. Стрельба, дуэли, движение и нажатия клавиш. Ничего не уходит в интернет.**

CS2-AimAudit превращает демку матча Counter-Strike 2 (`.dem`) в разбор «как от тренера». Он не тренирует аим — он показывает, что реально произошло в матче: откуда ты стрелял, с какой скоростью двигался, кто выстрелил первым и какие клавиши были зажаты.

## Возможности

- **Обзор** — все игроки в одной таблице: килы/смерти, точность, HS%, выстрелы на ходу, «рискованные выстрелы», кто стреляет первым, ошибка прицела, время дуэли. Отметь галочку у строки, чтобы проанализировать игрока; переключатель **Все столбцы** включает детальные метрики (включая точность 1-го выстрела и процент входов). K/D (килы/смерти и коэффициент), входы, трейды и ассисты зависят от фильтров **Сторона** и **Раунды**.
- **Стрельба** — зоны попаданий, скорость в момент каждого выстрела, график «скорость против дистанции» с кривой допустимой скорости, статистика по каждому оружию.
- **Дуэли** — каждая дуэль с дистанцией, тем, кто выстрелил первым, ошибкой прицела на первом выстреле и отметками: без прицела, через смок, вэллбенг, ослеплён. Ниже — дуэли по зонам карты и то, как начинался каждый раунд (первые дуэли, обе команды).
- **Импакт** — по каждому игроку: входы (победы/поражения), трейд-фраги, обменянные смерти, раунды 2k–5k, ассисты и флеш-ассисты.
- **Карта** — где выбранный игрок убивал и умирал, на радаре: твоя позиция (круг), позиция противника (пустой ромб) и линия между ними; синий — килл, красный — смерть; работает со всеми фильтрами, а у двухэтажных карт (Nuke, Vertigo) есть переключатель «Верхний / Нижний». Радары нужно скачать один раз, см. [Радары для карты](#радары-для-страницы-карта).
- **Таймлайн** — скорость (с порогом движения), поворот yaw, pitch и зажатые клавиши цветными полосами с легендой вокруг любой дуэли, с отметками первого выстрела и смерти, обрезанные в момент смерти (ввод после смерти — артефакт парсера, а не реальные действия). Переключи вид на **реплей раунда** — весь раунд на радаре, как мини-карта у зрителя: каждый игрок обеих команд, HP в кружке, стрелка направления взгляда и оружие в руках; линии — выстрелы, звёзды — попадания, крестики — смерти, лента справа — все киллы раунда, так что видно и куда ты стрелял, и кто тебя разменял. Слева — панель игроков (оружие на руках, HP; скрывается кнопкой), справа — карточки твоих дуэлей раунда: ещё не наступившие полупрозрачны, прошедшие — обычные, выбранная — с обводкой. Клик по карточке запирает ползунок в отрезок этой дуэли и показывает кнопки, которые нажимали оба дуэлянта; выход — повторным кликом, кнопкой ✕ или выбором другой дуэли. На таймлайне — отметки киллов (синие от CT, жёлтые от T); под ним — чипы раундов матча, подсвеченные цветом победившей стороны (победитель выводится по полной гибели стороны — событие round_end в CS2-демках не существует), клик переключает реплей на раунд. Колёсико зумит радар, перетаскивание ЛКМ двигает карту, двойной клик — сброс. Play / 0.5x / 0.25x, у двухэтажных карт (Nuke, Vertigo) — верхний и нижний уровни рядом.
- **Модель риска** — выстрел _рискованный_, если скорость превысила допустимую на этой дистанции до ближайшего живого врага: в упор — любая, на дальней — почти стоя. Обе дистанции настраиваются.
- **Отчёт о данных** — встроенные проверки аномалий (невозможные скорости, нераспознанные SteamID, пропавшие позиции…) и JSON-экспорт для баг-репортов.
- Вармап, урон по своим и не-оружейные события исключаются автоматически.
- Интерфейс на русском и английском.

## Быстрый старт

Проще всего:

- **Windows:** дважды кликни `start.bat` — он печатает, что делает (`[1/3] создаём venv…`, `[2/3] ставим пакеты, первый запуск занимает 1–3 мин…`, `[3/3] запускаем`) и останавливается с сообщением при любой ошибке.
- **macOS / Linux:** запусти `./start.sh` в терминале.

Или вручную:

```bash
git clone https://github.com/choompuy/cs2-aimaudit.git
cd cs2-aimaudit
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

Нужен Python 3.11+ (проверено на 3.11–3.14) и демка матча CS2 (`.dem`).

### Где взять демку

- **Premier / Соревновательный:** CS2 → Играть → _Ваши матчи_ → скачать демку. Демки хранятся ограниченное время — скачивай вскоре после матча.
- **FACEIT / ESEA:** ссылка на демку на странице матча. Сжатые файлы (`.dem.bz2`, `.dem.gz`, `.zip`, `.dem.zst`) приложение распакует само.

Потом выбери файл в приложении.

## Библиотека демок и где лежат файлы

Открыть демку можно одним способом: добавить файл (перетащи его в окно загрузки; подходят `.dem`, `.bz2`, `.gz`, `.zst` и `.zip`) или выбрать одну из сохранённых демок в списке. Каждая добавленная демка сохраняется в библиотеку, так что в следующий раз её достаточно выбрать, а последняя использованная открывается сама. Демка, которая уже есть в библиотеке (тот же файл под любым именем), второй раз не сохраняется.

Всё, что хранит приложение, лежит в одной папке рядом с `start.bat` / `start.sh`:

```
data/
  demos/        библиотека демок (обычные файлы; .dem можно положить и руками)
  cache/
    parsed/     разобранные демки, чтобы повторное открытие было мгновенным
    unpacked/   демки, распакованные из .bz2 / .gz / .zst / .zip
  radars/       радары (tools/fetch_radars.py)
  library.json  список демок        state.json  последняя демка и игрок
```

В приложении раздел *Библиотека и хранилище* показывает папку и размеры, удаляет демку и очищает кэш. `data/cache/` можно удалить руками в любой момент: она пересоберётся; невосстановимо только содержимое `demos/`. Папку можно перенести переменной окружения `AIMAUDIT_DATA_DIR`. `data/` не попадает в git.

## Радары для страницы «Карта»

Страница «Карта» рисует точки на настоящем радаре. Картинки радаров — это арт Valve, в репозиторий они не входят, поэтому скачай их один раз на своём компьютере:

```bash
python tools/fetch_radars.py
```

Скрипт скачивает картинки и калибровку из публичного релиза [awpy-data](https://github.com/pnxenopoulos/awpy-data) в папку `data/radars` рядом с `start.bat` (около 3 МБ). Приложение найдёт их там, в уже существующем кэше awpy (`~/.awpy`) или в папке из переменной `AIMAUDIT_RADAR_DIR`. Без радаров страница «Карта» всё равно работает: точки рисуются на пустой сетке в игровых юнитах.

## Приватность

Весь разбор выполняется локально на твоей машине. CS2-AimAudit не делает сетевых запросов (единственное исключение — `tools/fetch_radars.py`, который ты запускаешь сам один раз ради радаров), не собирает телеметрию и не отправляет демки никуда. Входящий в репозиторий `.streamlit/config.toml` дополнительно отключает анонимную статистику использования самого Streamlit (`gatherUsageStats = false`) — если заменяешь этот файл, сохрани настройку.

## Как читать цифры

- **Выстрелы на ходу** — сделаны при скорости выше порога. Сначала остановись (контрстрейф), потом стреляй.
- **Ошибка прицела** — угол между прицелом (с учётом отдачи) и головой врага в момент первого выстрела в дуэли. Несколько градусов и меньше — прицел уже был на голове.
- **Стреляет первым** — как часто ты стрелял первым в дуэлях, где кто-то стрелял.
- **Точность 1-го выстрела** — доля попаданий первым выстрелом серии (твоему выстрелу минимум ~0,35 с не предшествуют другие). Отражает плейсмент прицела; медианное движение мыши перед этими выстрелами (относительно твоей сенсы) показывает, насколько сильно ты «махаешь» перед выстрелом.
- **Процент входов** — как часто ты выигрываешь первый фраг раунда, когда участвуешь в нём (как киллер или жертва). Цифра энтри-игрока; низкая — пикай за гранатами или отдавай первый контакт тиммейту.
- **Трейды** — фраг считается трейдом, если он мстит за смерть тиммейта в течение 5 с (в том же раунде); «обменянные смерти» — доля твоих смертей, отомщённых так же, — это заслуга тиммейтов, а не только твоя.
- **Время дуэли** — от первого выстрела дуэли до килла/смерти. Долгие дуэли с кучей выстрелов указывают на проблемы со спреем/аимом.
- **Таймлайн** — ищи: стрельбу в движении, большие доводки прицела в последний момент, тайминг приседа и шифта.

Вкладка **«Гайд»** в приложении объясняет модель риска и ограничения: сенса, FPS и пинг в демках не хранятся (сырые дельты мыши, начиная с CS2, хранятся, но масштабируются сенсой); ошибка прицела приблизительная; дуэль определяется по окну времени, а не по линии видимости.

## Что-то выглядит неправильно?

Открой экспандер **«Отчёт о данных / отладка»** внизу страницы. Встроенные проверки подсвечивают аномалии данных, а скачиваемый JSON-отчёт содержит сырые поля парсера, по которым можно найти причину, — прикладывай его, когда [создаёшь issue](../../issues).

## Разработка

```bash
python tests/test_core.py        # синтетический матч, .dem не нужен
python tests/check_ui.py         # проверки i18n / схемы таблиц / слоёв
python tests/smoke_app.py --fast # сквозные AppTest-сценарии (фейковый парсер)
```

- `core/` — парсинг и все метрики (demoparser2), без UI.
- `app.py` — входная точка Streamlit (диспетчер); страницы лежат в `views/`,
  оболочка в `shell.py`, панель фильтров в `filters_ui.py`.
- `ui/tables.toml` — схема таблиц: форматы, сортировка, раскраска и полосы
  всех гридов описаны данными.
- `i18n.py` — строки русский/английский.
- `docs/ARCHITECTURE.md` — карта модулей, правила зависимостей и рецепты
  «как добавить метрику / колонку / страницу / фильтр».
- `docs/DEMOPARSER_NOTES.md` — конспект по API demoparser2.

Pull request'ы приветствуются. Баг-репорты с приложенным debug-JSON особенно ценны.
