# CS2-AimAudit 🎯

**Аудит твоего аима — локальный разбор демок CS2. Стрельба, дуэли, движение и нажатия клавиш. Ничего не уходит в интернет.**

CS2-AimAudit превращает демку матча Counter-Strike 2 (`.dem`) в разбор «как от тренера». Он не тренирует аим — он показывает, что реально произошло в матче: откуда ты стрелял, с какой скоростью двигался, кто выстрелил первым и какие клавиши были зажаты.

## Возможности

- **Обзор** — все игроки в одной таблице: килы/смерти, точность, HS%, выстрелы на ходу, «рискованные выстрелы», кто стреляет первым, ошибка прицела, время дуэли. Отметь галочку у строки, чтобы проанализировать игрока; переключатель **Все столбцы** включает детальные метрики.
- **Стрельба** — зоны попаданий, скорость в момент каждого выстрела, график «скорость против дистанции» с кривой допустимой скорости, статистика по каждому оружию.
- **Дуэли** — каждая дуэль с дистанцией, тем, кто выстрелил первым, ошибкой прицела на первом выстреле и отметками: без прицела, через смок, вэллбенг, ослеплён.
- **Таймлайн** — скорость / yaw / pitch / зажатые клавиши вокруг любой дуэли, обрезанные в момент смерти (ввод после смерти — артефакт парсера, а не реальные действия).
- **Модель риска** — выстрел _рискованный_, если скорость превысила допустимую на этой дистанции до ближайшего живого врага: в упор — любая, на дальней — почти стоя. Обе дистанции настраиваются.
- **Отчёт о данных** — встроенные проверки аномалий (невозможные скорости, нераспознанные SteamID, пропавшие позиции…) и JSON-экспорт для баг-репортов.
- Вармап, урон по своим и не-оружейные события исключаются автоматически.
- Интерфейс на русском и английском.

## Быстрый старт

Проще всего:

- **Windows:** дважды кликни `start.bat` — он печатает, что делает (`[1/3] создаём venv…`, `[2/3] ставим пакеты, первый запуск занимает 1–3 мин…`, `[3/3] запускаем`) и останавливается с сообщением при любой ошибке.
- **macOS / Linux:** запусти `./start.sh` в терминале.

Или вручную:

```bash
git clone https://github.com/choompuy/cs2-aimaudit.git
cd cs2-aimaudit
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
streamlit run app.py
```

Нужен Python 3.11+ (проверено на 3.11–3.14) и демка матча CS2 (`.dem`).

### Где взять демку

- **Premier / Соревновательный:** CS2 → Играть → _Ваши матчи_ → скачать демку. Демки хранятся ограниченное время — скачивай вскоре после матча.
- **FACEIT / ESEA:** ссылка на демку на странице матча. Сжатые файлы (`.dem.bz2`, `.dem.gz`, `.zip`, `.dem.zst`) приложение распакует само.

Потом выбери файл в приложении.

## Приватность

Весь разбор выполняется локально на твоей машине. CS2-AimAudit не делает сетевых запросов, не собирает телеметрию и не отправляет демки никуда. Входящий в репозиторий `.streamlit/config.toml` дополнительно отключает анонимную статистику использования самого Streamlit (`gatherUsageStats = false`) — если заменяешь этот файл, сохрани настройку.

## Как читать цифры

- **Выстрелы на ходу** — сделаны при скорости выше порога. Сначала остановись (контрстрейф), потом стреляй.
- **Ошибка прицела** — угол между прицелом (с учётом отдачи) и головой врага в момент первого выстрела в дуэли. Несколько градусов и меньше — прицел уже был на голове.
- **Стреляет первым** — как часто ты стрелял первым в дуэлях, где кто-то стрелял.
- **Время дуэли** — от первого выстрела дуэли до килла/смерти. Долгие дуэли с кучей выстрелов указывают на проблемы со спреем/аимом.
- **Таймлайн** — ищи: стрельбу в движении, большие доводки прицела в последний момент, тайминг приседа и шифта.

Вкладка **«Гайд»** в приложении объясняет модель риска и ограничения: движения мыши, сенса, FPS и пинг в демках не хранятся; ошибка прицела приблизительная; дуэль определяется по окну времени, а не по линии видимости.

## Что-то выглядит неправильно?

Открой экспандер **«Отчёт о данных / отладка»** внизу страницы. Встроенные проверки подсвечивают аномалии данных, а скачиваемый JSON-отчёт содержит сырые поля парсера, по которым можно найти причину, — прикладывай его, когда [создаёшь issue](../../issues).

## Разработка

```bash
python tests/test_core.py   # синтетический матч, .dem не нужен
python tests/check_ui.py    # проверки согласованности i18n / API
```

- `core.py` — парсинг и все метрики (demoparser2), без UI.
- `app.py` — интерфейс на Streamlit.
- `i18n.py` — строки русский/английский.
- `docs/DEMOPARSER_NOTES.md` — конспект по API demoparser2.

Pull request'ы приветствуются. Баг-репорты с приложенным debug-JSON особенно ценны.
